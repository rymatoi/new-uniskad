Добавление единиц измерения

Для каждого термина имеется возможность установки единиц измерения. Для этого следует нажать правой кнопкой на соответствующий термин и выбрать пункт «Открыть» (Рисунок 121).

Рисунок 121

В центральной части экрана появится список единиц измерения, которые соответствуют данному термину (Рисунок 122).

Рисунок 122

Для того чтобы добавить единицу измерения следует выбрать пункт «Добавить». После выбора пункта появиться следующее диалоговое окно (Рисунок 123).

Рисунок 123

В данном окне мы можем выбрать соответствующую единицу измерения. Для более удобного поиска можно ввести название желаемой единицы измерения в строку поиска. Для выбора следует выбрать соответствующую единицу измерения и нажать кнопку «ОК» или нажать два раза левой кнопкой мыши на единицу измерения. После добавления данная единица измерения будет отображаться в списке единиц измерения для данного термина.
