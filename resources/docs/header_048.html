Удаление рабочих данных

Кроме сохранения первичных файлов эксперимента реализована и возможность их удаления без предварительной обработки. Для этого выберем необходимый файл и нажмем на него правой клавишей мыши. В открывшемся диалоговом окне необходимо выбрать пункт «Удалить» (Рисунок 73)

Рисунок 73

При нажатии на пункт удалить данный объект будет удален из изделий.
