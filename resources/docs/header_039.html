Добавление роли для пользователя

В нижней части карточки пользователей имеется список ролей, членом которых является данный пользователь. Нажав, находящуюся справа кнопку «Добавить» мы откроем окно диалога выбора ролей, которые можно добавить данному пользователю (Рисунок 54). (Роли, членом которых данный пользователь уже является, автоматически исключаются из данного списка)

Рисунок 54

При этом мы можем «галочками» сразу выделить несколько ролей. (Тем самым будет инициировано групповое добавление ролей). В том случае, если список ролей велик, начав вводить в поле «Выберите роль» первые буквы названия интересующей нас роли, мы тем самым используем режим «фильтрации», что позволяет быстро найти интересующую администратора роль. Так, например, ввод двух букв «Ад» сокращает наш список доступных ролей до единственной роль «Администратор UNISKAD» (Рисунок 55).

Рисунок 55

Следует отметить, что поиск осуществляется по любому вхождению введенного буквенного фрагмента без учета регистра букв, поэтому, введение просто «А» не помогает, так как в роли «Новый пользователь», буква «а» также имеется.

Аналогично, нажатие кнопки «Удалить» приводит к отключению пользователя от текущей (выбранной в карточке пользователя) роли. Как всегда, завершение операции должно сопровождаться нажатием кнопки «ОК».
