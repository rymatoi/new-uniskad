Аппроксимация графика

Нажмем на график и выберем кнопку «Аппроксимировать» будет открыто следующее окно (Рисунок 278).

Рисунок 278

В этом окне обходимо ввести название для аппроксимации, которое будет отображаться в легенде. Из выпадающего списка доступен выбор типа полинома (Рисунок 279)

Рисунок 279

Доступен выбор полиномиального, полинома Чебышева, полинома Лежандра. Выберем полином Чебышева и степень полинома 14 (важно отметить, что максимальная степень доступная для выбора 20) (Рисунок 280).

Рисунок 280
