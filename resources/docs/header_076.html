Поиск по имени и дате создания

В базе проектов реализована функция поиска проектов по имени и дате создания. Для этого необходимо воспользоваться строкой поиска (Рисунок 131)

Рисунок 131

Введем в строку поиска слово asd (Рисунок 132)

Рисунок 132

Найденные совпадения выделены в дереве проекта желтым цветом.

При поиске по дате, введенной в строку поиска, будут выделены те испытания, в которых содержится данная дата.
