Словарь единиц измерения

Для каждой единицы измерения представлено контекстное меню для взаимодействия с данной единицей измерения, которое вызывается путем нажатия на правую кнопку мыши (Рисунок 126).

Рисунок 126

Каждую единицу измерения можно просмотреть, если выбрать пункт «Открыть». Настроить её внешний вид в отображении в дереве словаря с помощью пункта «Настроить», а также «Переместить» и «Переименовать». Удалить с помощью соответствующего пункта.
