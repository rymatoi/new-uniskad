Восстановление удаленных рабочих данных

При необходимости данный объект можно восстановить. Для этого в меню изделия нажмем на кнопку «шестеренка» (Рисунок 74)

Рисунок 74

После чего откроется окно (Рисунок 75)

Рисунок 75

Выберем пункт «Показывать удаленные». Удаленные объекты будут отображаться в дереве и отмечены зачеркиванием красной линией (Рисунок 76)

Рисунок 76

Выбрав удаленный объект, нажмем на него правой клавишей мыши, нам будут доступны следующие действия (Рисунок 77)

Рисунок 77

При нажатии на пункт «Восстановить», данный объект будет восстановлен и перестанет быть зачеркнутым красной линией (Рисунок 78).

Рисунок 78

При выборе пункта «Удалить без возможности восстановления» данный файл будет удален окончательно и исчезнет из дерева. Чтобы скрыть удаленные объекты снова нажмем на кнопку «шестеренка» необходимо снять галочку с пункта «Показывать удаленные» (Рисунок 79).
