Роли в программе UNISKAD

У каждого пользователя есть своя роль, которая определяет набор возможных действий данного пользователя. В нашей программе имеется несколько ролей: «Пользователь UNISKAD», «Администратор UNISKAD»,

Пользователь UNISKAD ­ базовая роль, которая предоставляет базовый набор возможностей.

Администратор UNISKAD ­ пользователь, имеющий данную роль, имеет тот же набор возможностей что и пользователь с ролью «Пользователь UNISKAD». Также администратор имеет возможность администрирования и управления набором возможностей пользователей.
