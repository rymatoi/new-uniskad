Настройки

При нажатии на кнопку «Файл», далее «Настройки» (Рисунок 16).

Рисунок 16

Открывается следующее окно (Рисунок 17).

Рисунок 17

Правой кнопкой мыши выбираем «Внешний вид», открывается следующее окно (Рисунок 18).

Рисунок 18

Далее необходимо выбрать шрифт и его размер и нажать кнопку «Ок». Каждый пользователь программы может настроить тот вид приложения, который будет удобен для него.
