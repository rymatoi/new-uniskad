Настройка испытания, связанная с заданием условия

При настройке испытания можно настроить условия (Рисунок 226)

Рисунок 226

Нажимаем кнопку «Добавить условие» в окне «Настройка условий» появится окно для ввода значений (Рисунок 227).

Рисунок 227

В настройке условий содержится поле ввода названия кривой, для отображения в легенде. По умолчанию в нем указано название таблицы и к нему можно добавить комментарий для обозначения созданного условия. Выберем параметр для сортировки, например Р4, в условия отображения если X= введем значение 7,22 выберем цвет, вид точки и размер точки следующим образом (Рисунок 228)

Рисунок 228

Далее установим галочку на «Применить условия» (Рисунок 229)

Рисунок 229

И нажмем кнопку «ОК». Обратимся к виду графика для установленных параметров (Рисунок 230)

Рисунок 230

На графике отображаются точки, соответствующие данному условию. Добавим в настройке испытания еще одно условие, для этого нажмем на кнопку «Добавить условие» и заполним соответствующую форму следующим образом (Рисунок 231)

Рисунок 231

Посмотрим на график, соответствующий этом двум условиям (Рисунок 232)

Рисунок 232
