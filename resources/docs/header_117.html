Добавление на график линий и точек

Для графика реализована возможность ручного добавления, в том числе импорт точек из текстового структурированного файла извне. Для этого откроем график и нажмем на кривую этого графика правой клавишей мыши, откроется следующее окно (Рисунок 270).

Рисунок 270

Выберем пункт «Копировать значения». Далее откроем новый файл в Excel и вставим скопированные значения (Рисунок 271)

Рисунок 271

Как мы видим, данный файл содержит информацию о количестве точек и значениях параметра. При копировании значений кривой аппроксимации, будут скопированы данные аппроксимаций со всех графиков в этом проекте, в которых ось ОХ та же. Скопированные значения будут представлять из себя несколько столбцов, где первый столбец — это значения по оси ОХ, а остальные столбцы — это соответствующие им значения по оси ОУ из всех графиков аппроксимации.

Далее открываем любой график и нажимаем в любом свободном месте графика правой клавишей мыши, появится кнопка «Вставить» (Рисунок 272).

Рисунок 272

Нажимаем на кнопку «Вставить», будет добавлена кривая, соответствующая скопированным значениям (Рисунок 273)

Рисунок 273

На графике вставленная кривая отображена желтым цветом. Аналогичным образом можно вставить кривую извне. Для этого необходимо в Excel создать таблицу из двух столбцов со значениями по оси x и по оси y. В первой строке первого столбца нужно ввести название кривой, во второй строке первого столбца количество точек (Рисунок 274).

Рисунок 274

Выделить внесенные данные в Excel, скопировать их и в графике нажать «Вставить». На график будет добавлена кривая по заданным значениям (Рисунок 275).
