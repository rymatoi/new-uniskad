Рабочие данные

Данный пункт меню предназначен для работы с данными, а именно с так называемыми «Изделиями». Под изделиями в дальнейшем будем понимать следующую иерархию: изделие состоит из моделей, модели из сборок, сборка же может состоять из папок и испытаний. Под испытаниями подразумеваются Excel таблицы. При двойном нажатии на любой из объектов в левой части экрана будет находиться характеризующая данный объект информация (Рисунок 66).
