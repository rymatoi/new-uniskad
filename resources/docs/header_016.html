Действия с ролями

Нажав на любую роль правой кнопкой мыши, появится окно (Рисунок 28).

Рисунок 28

Кнопка «Открыть» открывает список разрешений для данного пользователя.

Кнопка «Переместить» позволяет переместить данную роль в списке ролей. Например, переместить вверх на одну позицию, переместить вниз на одну позицию.

Кнопка «Удалить» позволяет удалить данную роль из списка ролей.
