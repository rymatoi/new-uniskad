Принудительное отключение пользователя при бездействии

Также администратор может установить для каждого пользователя принудительное отключение через определенное количество минут. Нужно ввести количество минут в соответствующей строке. Например, для пользователя User8 установим 30 минут (Рисунок 53).

Рисунок 53

Далее необходимо нажать на кнопку «ОК» внизу страницы. Для данного пользователя будет установлено принудительное отключение через 30 минут.
