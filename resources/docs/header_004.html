Авторизация

Запуск приложения начинается с меню авторизации. В данном окне (Рисунок 10) пользователю предлагается ввести «Имя пользователя» и «Пароль».

Рисунок 10

По умолчанию, при вводе пароля, содержимое данного поля скрыто и замаскировано символом «*». По желанию пользователя данное содержимое можно сделать видимым. Для это требуется нажать на кнопку, изображающую глаз, на который указывается красная стрелка (Рисунок 11).

Рисунок 11

После нажатия содержимое поля будет видно, а кнопка изменит свой вид на зачеркнутый глаз. Окно авторизации будет иметь следующий вид (Рисунок 12).

Рисунок 12
