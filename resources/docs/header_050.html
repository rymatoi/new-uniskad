Настройка отображения рабочих данных

Для изменения внешнего вида объекта требуется нажать на объект правой кнопкой мыши и выбрать пункт меню настроить (Рисунок 80).

Рисунок 80

Таким образом, изменяя внешние параметры: шрифт, цвет теста, цвет фона или иконку, – мы сможем получить следующий внешний вид объекта (Рисунок 81).

Рисунок 81

При обращении к первичным данным нередко возникает задача поиска в первичных данных по заданным критериям пользователя, например по имени параметра. С помощью комбинации клавиш Ctrl+F выводится окно, в которое необходимо ввести значение параметра, по которому будет осуществляться поиск.
