Дерево проекта

Для того чтобы открыть любой проект необходимо выбрать его в списке проектов и внизу окна Мои проекты нажать кнопку Открыть (Рисунок 152).

Рисунок 152

После выбора соответствующего проекта в правой части экрана будет открыт интерфейс, в котором будет размещено дерево проекта (Рисунок 153).

Рисунок 153

Элементом проекта, на основе которого в дальнейшем будут строиться графики и поля является Excel таблица, которая характеризует испытания.
