Действия с пользователями

При нажатии правой кнопкой мыши на данного пользователя откроется следующее окно (Рисунок 60).

Рисунок 60

Кнопка «Открыть» открывает окно настроек данного пользователя.

Кнопка «Переместить» позволяет переместить пользователя на одну позицию вверх, на одну позицию вниз (Рисунок 61).

Рисунок 61

Кнопка «Удалить» позволяет удалить данного пользователя из списка пользователей.
