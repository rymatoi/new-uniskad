Перенос неподтвержденных синонимов в список подтвержденных

Для переноса в список подтверждённых синонимов существует специальный пункт меню. Для открытия диалогового окна по подтверждению следует кликнуть правой кнопкой мыши и выбрать из списка пункт «Подтвердить» (Рисунок 115). После этого будет открыто следующее окно (Рисунок 116).

Рисунок 115

Рисунок 116

Для подтверждения следует выбрать «Синоним» и выбрать для какого термина данный термин будет служить синоним. Данный термин будет являться дочерним элементом для выбранного термина (Рисунок 117).

Рисунок 117

В данном случае для термина “00” термин: “_N1пр”, является синонимом.

Также для добавления синонима необязательно иметь его в списке неподтверждённых синонимов. Для этого следует выбрать термин, для которого вы хотите добавить синоним, нажать правой кнопкой мыши для открытия контекстного меню и выбрать пункт «Добавить», далее пункт «Синоним» (Рисунок 118).

Рисунок 118

После выбора пункта «Синоним» понадобится только ввести его название в диалоговом окне (Рисунок 119).

Рисунок 119

После добавления синонима, как и в предыдущем случае, он будет отображаться в списке дочерних элементов для термина.
