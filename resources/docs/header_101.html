Настройка испытания, связанная с внешним видом графика

Кроме стандартной работы с испытаниями можно выполнять настройку испытания. Для этого в окне проектов выберем нужное испытание и нажмем правую клавишу мыши, откроется следующее выпадающее меню (Рисунок 221)

Рисунок 221

Выберем пункт «Настроить..», далее «Элемент» (рисунок 222)

Рисунок 222

Откроется следующее окно (Рисунок 223)

Рисунок 223

В данном окне задаются настройки отображения кривой. Можно ввести название кривой, например введем название «Тестовое испытание 1 от 18 апреля 2024». Далее задается цвет линии на графике для заданного испытания, тип линии (по умолчанию установлен тип линии Прозрачная), ее толщина, вид точки (выпадающий список содержит следующий выбор: круг, квадрат, треугольник вверх, ромб, звезда, пятиугольник, восьмиугольник, крест, плюс, треугольник вниз, треугольник вправо, треугольник влево), размер точки, цвет границы точки (по умолчанию установлен цвет границы точки Черный), заливка точки. Данную настройку испытания можно отображать на графиках, для этого установим «галочку» в соответствующем окне. Пример заполнения представлен на рисунке 224.

Рисунок 224

Далее необходимо нажать кнопку «ОК» внизу страницы. Данное отображение будет применяться к построению графика. Построение графиков будет рассмотрено в пункте График, приведем сейчас только вид графика, построенного по заданной настройке испытания для понимания влияния заданных параметров (Рисунок 225).
