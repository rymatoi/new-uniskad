Настройка выравнивания данных в столбце

Настройка столбца заключается в настройке выравнивания данных в выбранном столбце. Выберем столбец, нажмем на его название правой клавишей мыши и выберем пункт «Настроить..» откроется меню настройки столбца (Рисунок 184)

Выберем необходимое выравнивание для столбца, например, выберем выравнивание «Слева» и нажмем кнопку «Сохранить». Для столбца с номером 15 установлено выравнивание данных по левому краю (Рисунок 186)

Рисунок 186

Аналогичным образом можно установить выравнивание в нескольких столбцах, для этого нужно выбрать несколько столбцов и, нажав на название одного из выделенных столбцов, выбрать пункт «Настроить..»
