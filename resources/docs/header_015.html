Добавление новых ролей

При необходимости можно добавить новую роль. В любом свободном месте поля «Роли» нужно нажать правой кнопкой мыши. Появится окно «Добавить» при наведении, на которое появится окно «Роль» (Рисунок 24).

Рисунок 24

Нажимаем на окно «Роль» откроется окно, в котором необходимо заполнить свободные поля (Рисунок 25).

Рисунок 25

Создадим новую роль, например «Новый пользователь». Заполним свободные поля (Рисунок 26).

Рисунок 26

Нажмем кнопку «Ок» данная роль отобразиться в списке ролей (Рисунок 27).

Рисунок 27
