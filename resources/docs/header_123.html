Работа с линейкой

Для линий интерполяции и аппроксимации доступна функция линейки. Выберем первую кривую, нажмем на нее правой клавишей мыши и из выпадающего списка выберем «Метка для линейки» данная точка будет принята за начальную точку для измерения расстояния между графиками (Рисунок 291, Рисунок 292).
