Добавление графика

Для добавления графика следует нажать правой кнопкой мыши на папку «Графики», откроется следующее окно (Рисунок 238).

Рисунок 238

Первые три пункта «Настроить», «Переместить» и «Переименовать» описывают стандартные действия с элементами дерева.

Выберем пункт «Добавить», далее «График» (Рисунок 239).

Рисунок 239

Откроется окно выбора и настройки параметров для графика (Рисунок 240).

Рисунок 240

Построим график зависимости одного параметра от другого. Выберем в качестве первого параметра Р*06а5, в качестве второго КПДк, настройка отображений на графиках по группам установим по умолчанию (Рисунок 241).

Рисунок 241

Нажимаем кнопку «ОК». После этого в качестве дочернего элемента папки «Графики» будет отображаться график, построенный на данных текущих таблиц (Рисунок 242).

Рисунок 242

Откроем этот график. Сделать это можно двойным нажатием мыши по этому графику, либо, выделив этот график и нажав правой клавишей мыши. Откроется следующее окно (Рисунок 243).

Рисунок 243

Выбираем пункт «Открыть» и отрывается график зависимости параметра КПДк от параметра Р*06а5 для трех добавленных в проект испытаний (Рисунок 244).

Рисунок 244
