Словари

Словари предназначены для фиксирования значения определённых терминов, а также их уточнения, если они требуются. В программе предусмотрены «Словарь синонимов» предназначен для приведения к единому стандарту имен (параметров данных), поступающих из различных источников и «Словарь единиц измерения» для задания сокращений соответствующим единицам измерения. Для того, чтобы выбрать нужный словарь, следует выбрать пункт «Словари» на тулбаре в верхней части экрана. После открытия пункта будет предложен выбор из словарей. (Рисунок 109)
