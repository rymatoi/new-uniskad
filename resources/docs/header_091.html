Добавление строки в таблицу

Несмотря на то, что таблицы строятся на основе имеющихся данных, в таблицы можно добавлять строки для дополнительных подсчётов. При нажатии правой клавишей мыши на название любой выделенной строки таблицы данных открывается следующее окно (Рисунок 178).

Рисунок 178

При нажатии на кнопку «Добавить строку» появляется окно (Рисунок 179).

Рисунок 179

Введем название параметра, например «Новый параметр» и нажмем кнопку «Ок». Новая строка с именем «Новая параметр» появится в нижней части таблицы (Рисунок 180).

Рисунок 180

В каждую ячейку данной строки при необходимости можно ввести значения или формулы для вычисления.
