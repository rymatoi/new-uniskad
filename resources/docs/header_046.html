Добавление рабочих данных

Для добавления объектов используется кнопка добавить при нажатии правой кнопки мыши (Рисунок 67).

Рисунок 67

В изделие мы можем добавить модель, в модель можно добавить сборку, в сборку можно добавлять испытания, папки и файлы. Важно отметить, что в каждый объект можно добавлять папку, которая в зависимости от места в иерархии будет хранить соответствующие элементы. То есть папка, созданная в изделии, будет хранить модели и т. д. (Рисунок 68).

Рисунок 68

Если будет выбран объект «Папка», то в самом дереве будет предоставлена возможность раскрытия/сокрытия элементов данной папки.
