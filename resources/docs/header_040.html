Добавление нового пользователя

Нажав в свободном месте поля «Пользователи» правой клавишей мыши появляется окно добавить. Это позволяет добавлять новых пользователей. Выбираем «Добавить» «Пользователя» (Рисунок56).

Рисунок 56

Далее появится окно, в котором необходимо заполнить свободные поля (Рисунок 57).

Рисунок 57

Пример заполнения приведен на следующем рисунке (Рисунок 58). При введении пароля он скрывается символами «*».

Рисунок 58

Важно! Для создания пользователя должны быть заполнены все поля.

Далее необходимо нажать на кнопку «Ок» и данный пользователь появится в поле «Пользователи» (Рисунок 59).

Рисунок 59

Нельзя создать нового пользователя если пользователь с таким логином существует или есть в списке удаленных пользователей.
