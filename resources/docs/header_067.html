Удаление из списка синонимов

Если вдруг термин не является синоним, то данный элемент можно удалить из списка синонимов. Для этого следует нажать на данный термин правой кнопкой мыши и выбрать пункт «Открепить» (Рисунок 120).

Рисунок 120

После открепления данный термин будет перемещён в раздел «Неподтверждённые синонимы».
