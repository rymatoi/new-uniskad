Восстановление удаленного пользователя

При нажатии правой клавишей мыши на удаленного пользователя появляется окно (Рисунок 64).

Рисунок 64

Кнопка «Восстановить» позволяет восстановить данного пользователя, то есть переместить его обратно из списка удаленных в список пользователей. Копка «Удалить без возможности восстановления» полностью удаляет данного пользователя, он пропадает из списка, восстановить этого пользователя будет нельзя.
