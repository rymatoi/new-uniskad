Управление ролями

Управление ролями осуществляется с помощью соответствующего меню. Для его открытия следует выбрать пункт «Управление ролями». После в левой части экрана появится интерфейс для настройки каждой роли (Рисунок 22).

Рисунок 22

Для изменения разрешений для определённой роли следует выбрать данную роль из имеющегося списка. Здесь можно изменить набор пунктов (кнопок), отображаемые для пользователя с соответствующей ролью. Для примера будет представлен список разрешений для обычного пользователя. В раскрытом виде он будет выглядеть следующим образом (Рисунок 23).

Рисунок 23

Примечание: при нажатии на знак «минус» будет скрыт только интерфейс с названиями ролей, настройки отдельного пользователя, если они были выбраны, закрыты не будут.
