Задание количества значащих цифр

Кроме формул в таблице можно задавать количество значащих цифр. Для этого выбираем строку. Нажимаем на ее название правой клавишей мыши. Откроется следующее окно (Рисунок 171).

Рисунок 171

При выборе пользователем пункта «Настроить..», открывается следующее окно (Рисунок 172).

Рисунок 172

В данном окне можно задать количество значащих чисел, после этого необходимо нажать на кнопку «Сохранить». После этого в данной строке таблицы все данные будут содержать количество значащих цифр, введенных пользователем.
