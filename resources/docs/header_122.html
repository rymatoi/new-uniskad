Интерполяция кривой

Нажмем на график и выберем кнопку «Интерполировать» будет открыто следующее окно (Рисунок 288).

Рисунок 288

В этом окне обходимо ввести название для интерполяции, которое будет отображаться в легенде. Из выпадающего списка доступен выбор типа полинома (Рисунок 289)

Рисунок 289

Доступен выбор кубическая и квадратичная интерполяция. Выберем кубическую интерполяцию и нажмем на кнопку ОК. На графике интерполяция будет иметь вид (Рисунок 290)
