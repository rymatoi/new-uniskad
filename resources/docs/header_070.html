Словарь единиц измерения

Словарь единиц измерения предназначен для хранения всех единиц измерений. Для того, чтобы просмотреть/изменить словарь единиц измерения следует в пункте главного меню «Словари» выбрать пункт «Словарь единиц измерения» (Рисунок 124).

Рисунок 124

После выбора соответствующего пункта будет открыт словарь единиц измерения (Рисунок 125).
