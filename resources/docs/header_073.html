Добавление новых единиц измерения

Для добавления новой единицы измерения следует нажать правой кнопкой мыши в любом пустом месте словаря и выбрать пункт «Добавить», затем пункт «Единица измерения» (Рисунок 127).

Рисунок 127

После выбора данного пункта будет открыто окно для добавления новой единицы измерения. Каждая единица характеризуется названием, сокращением и описанием (Рисунок 128).

Рисунок 128

После добавления единица измерения будет отображена в словаре единиц измерения в конце списка.
