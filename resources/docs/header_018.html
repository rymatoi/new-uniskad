Восстановление удаленных ролей

При нажатии правой клавишей мыши на удаленного пользователя появляется окно (Рисунок 31).

Рисунок 31

Кнопка «Восстановить» позволяет восстановить данную роль, то есть переместить ее обратно из списка удаленных в список ролей. Копка «Удалить без возможности восстановления» полностью удаляет данную роль, она пропадет из списка, восстановить эту роль будет нельзя. Удалим без возможности восстановления созданную нами роль «Новый пользователь». В списке ролей ее нет (Рисунок 32).

Рисунок 32

Если необходимо скрыть список удаленных ролей снова нажимаем на кнопку шестеренка и нажимаем правой клавишей мыши, чтобы снять галочку с пункта «Показывать удаленные».

Важно! Нельзя создать новую роль если роль с таким названием существует или есть в списке удаленных ролей.
