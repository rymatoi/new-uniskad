Выход

Для завершения работы программы предусмотрено несколько вариантов. Первый вариант - выход через пункт «Файл». Для выхода требуется нажать на соответствующий пункт в меню «Файл». После нажатия на пункт «Выход» работа программы будет завершена (Рисунок 19).

Рисунок 19

Второй вариант - завершение работы путём закрытия с помощью стандартной кнопки закрытия приложений в верхней части экрана.
