Пункт меню «Окно»

Говоря про отображение окон следует упомянуть, что его также можно настроить в пункте «Окно». Данный пункт дает пользователю возможность увидеть список доступных ему окон (Рисунок 9).

Рисунок 9

Отметка в виде «галочки» напротив определённого названия означает, открыто ли данное окно. Чтобы скрыть окно с помощью данного пункта необходимо убрать отметку напротив названия окна, чтобы открыть – соответственно, вернуть отметку. Установка «галочки» не загружает режимы приложения.
