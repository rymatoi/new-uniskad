Переименование объекта

Любой объект можно переименовать для этого необходимо нажать правой клавишей мыши на выбранный объект и в появившемся меню выбрать переименовать (Рисунок 82).

Рисунок 82

После этого откроется окно, в которое необходимо ввести новое наименование элемента (Рисунок 83).

Рисунок 83

После этого необходимо нажать кнопку «Ок», файл будет отображаться в дереве с новым именем.
