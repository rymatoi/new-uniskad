Передача проекта другому пользователю

Проект со всеми его элементами можно передать другому пользователю. Передадим проект с названием «Test 2024 05 25» другому пользователю. Выделим данный проект и нажмем на кнопку «Отправить копию» (Рисунок 144).

Рисунок 144

Откроется окно выбора пользователя (Рисунок 145)

Рисунок 145

Выберем пользователя, которому нужно передать проект из представленного списка, например 123 12345. Выделим его и нажмем кнопку Выбрать (Рисунок 146).

Рисунок 146

Копия проекта будет передана данному пользователю и отобразится у него в окне Проекты других пользователей (Рисунок 147).

Рисунок 147

Окно Проекты других пользователей сгруппированы по имени создателей проекта. Развернув эту группировку, мы можем увидеть все проекты, которые были переданы данным пользователем.
