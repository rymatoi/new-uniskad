Выравнивание данных в столбце

Для выбранного столбца можно установить выравнивание текста. Для этого необходимо выбрать столбец и нажать на название столбца (Рисунок 88)

Выберем необходимое выравнивание для столбца, например, выберем выравнивание «Справа» и нажмем кнопку «Сохранить» (Рисунок 91)

Рисунок 91

Для столбца с номером 2 установлено выравнивание данных по правому краю (Рисунок 92)

Рисунок 92

Аналогичным образом можно установить выравнивание в нескольких столбцах, для этого нужно выбрать несколько столбцов и, нажав на название одного из выделенных столбцов, выбрать пункт «Настроить..»
