Создание шаблона формулы

Для более удобной работы с формулами в таблицах испытаний реализована функция создания шаблонных формул. Для создания шаблонной формулы выберем в тулбаре кнопку . Откроется следующее окно (Рисунок 187).

Рисунок 187

Нажмем на кнопку «Добавить», откроется следующее окно (Рисунок 188)

Рисунок 188

Введем название параметра, например Сумма значений и нажмем кнопку «Ок» (Рисунок 189)

Рисунок 189

Список шаблонных формул будет выглядеть теперь следующим образом (Рисунок 190)

Рисунок 190

Нажмем на кнопку «Изменить», откроется следующее окно (Рисунок 191)

Рисунок 191

Нажмем на кнопку «Добавить», откроется окно с выбором параметров (Рисунок 192)

Рисунок 192

Установим галочки на параметры, которые будут входить в формулу, например Т*516а5 и Sigma(вх), далее необходимо нажать на кнопку «Выбрать» (Рисунок 193).

Рисунок 193

Окно с выбором параметров для формулы будет выглядеть следующим образом (Рисунок 194)

Рисунок 194

Теперь параметру Т*516а5 присвоена переменная Х0, а параметру Sigma(вх) – Х1. В строке выражение для формулы, введем необходимую нам формулу Х0+Х1 (Рисунок 195)

Рисунок 195

И нажмем кнопку «Сохранить». Список шаблонных формул теперь выглядит следующим образом (Рисунок 196)

Рисунок 196

Если в формулу необходимо внести изменения, то необходимо нажать на кнопку «Изменить» и снова будет открыто окно с выбором параметров и строкой ввода формулы.

Далее необходимо нажать на кнопку «Добавить строки в таблицу» (Рисунок 197)
