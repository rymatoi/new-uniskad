Изменение последовательности шаблонных формул

В редакторе формул каждой новой формуле присвоен порядковый номер. Это сделано для того, чтобы можно установить последовательность вычислений. Например, создадим еще одну формулу (Рисунок 199)

Рисунок 199

Справа содержатся кнопки «Вверх» и «Вниз» позволяющие переместить созданную формулу в списке формул выше или ниже (Рисунок 200).

Рисунок 200

Переместим формулу 2 выше, для этого выделим эту формулу и нажмем кнопку «Вверх». Формула 2 переместилась на одну позицию выше (Рисунок 201).

Рисунок 201

Для сохранения этих изменений необходимо нажать кнопку «Сохранить» (Рисунок 202)
