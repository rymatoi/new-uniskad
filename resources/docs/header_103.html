Настройка испытания, связанная с фильтрацией

Еще одной из настроек испытания является настройка фильтрации. Данная настройка позволяет реализовать функционал полуавтоматического определения битого замеренного параметра через условие (фильтр) соответствия значения в выбранных строках указанному критерию. Выполнение условия исключает точку из графиков и расчетов.

Выберем испытание, нажмем на него правой клавишей мыши, из выпадающего меню выберем «Настроить..», далее «Элемент». Откроется окно настройки испытания. В правой части окна Настройка фильтрации (Рисунок 233)
