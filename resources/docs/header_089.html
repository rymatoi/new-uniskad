Пересчет единиц измерения в таблице

В таблице данных можно по параметрам можно производить пересчет единиц измерения. Для этого выбираем строку и нажимаем на ее название правой клавишей мыши, откроется следующее окно (Рисунок 173).

Рисунок 173

Выбираем пункт «Настроить..», открывается следующее окно (Рисунок 174).

Рисунок 174

Выбираем из выпадающего списка ту единицу измерения, в которой происходило фиксирование данного параметра, и единицу измерения, в которую мы хотим перевести значение данного параметра (Рисунок 175).

Рисунок 175

Далее нажимаем кнопку «Сохранить». В данной строке произойдет пересчет данных значений.
