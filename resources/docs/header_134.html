Cохранение файла поля в формате EMF

Нажатие на иконку , позволяет сохранить файл данного графика в формате EMF на персональном компьютере пользователя (Рисунок 323).

Рисунок 323

При необходимости можно изменить имя файла, выбрать папку для сохранения, далее необходимо нажать на кнопку «Сохранить».
