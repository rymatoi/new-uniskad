Создание шаблонов графиков

предусмотрена возможность создания шаблонов графиков. Выберем папку «Графики» и нажмем на нее правой клавишей мыши, будет открыто следующее окно (Рисунок 294)

Рисунок 294

Выберем пункт «Сохранить шаблон графиков», откроется следующее окно (Рисунок 295)

Рисунок 295

В данное окно необходимо ввести имя шаблона и затем нажать кнопку «Ок». Введем имя шаблон, например Шаблон от 18.05.2024, (Рисунок 296)

Рисунок 296

Весь набор графиков, содержащихся в папке «Графики» будет добавлен в шаблон для данного пользователя.
