Количество попыток авторизации с неверным паролем

Администратор может установить для каждого пользователя количество попыток для входа. Необходимо ввести необходимое число попыток в соответствующей строке. Например, для пользователя User8 установим 10 попыток для входа (Рисунок 52).

Рисунок 52

Далее необходимо нажать на кнопку «ОК» внизу страницы. Для данного пользователя будет установлено 10 попыток авторизации с неверным паролем.
