Контроль версий

Контроль версий является важным инструментом в программе. С помощью данного инструмента имеется возможность сохранять различные версии испытания с пользовательскими пометками. Благодаря контролю версий можно с лёгкостью перемещаться между этими версиями.

Для того чтобы открыть пункт «Контроль версий» необходимо нажать правой кнопкой мыши на соответствующее испытание и выбрать пункт «Контроль версий» (Рисунок 107).

Рисунок 107

После выбора данного пункта у пользователя будет открыто следующее окно (Рисунок 108).

Рисунок 108

Таким образом, можно создать новую версию таблицы или вернуться к старой версии. В проект добавляется последняя версия. Таким образом происходит фиксация текущего состояния конкретного набора первичных данных.
