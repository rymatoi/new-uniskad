Переключение ролей пользователя в рамках текущего подключения

Нажатием на текущую роль раскрывается список ролей доступных для данного пользователя и появляется возможность выбрать необходимую роль.

В программе для ЭВМ «Uniskad версии 3.0» реализована возможность переключения ролей пользователя в рамках текущего подключения. Нажатием на текущую роль раскрывается список ролей доступных для данного пользователя и появляется возможность выбрать необходимую (Рисунок 21).
