Пункты меню

При разработке программы для ЭВМ «Uniskad 3.0» была реализована возможность пользователей настраивать расположение элементов, так называемый режим многооконности. Его суть заключается в том, что пользователи могут отделять, перемещать и закреплять отдельные окна в разных частях программы и за ее границами. Меню программы, на которые может поставить галочку пользователь, полностью зависят от его роли. Определим роль как функцию, которую выполняет пользователь. Например, если пользователь имеет роль "Пользователь UNISKAD", то он может использовать все возможности программы для работы и выполнения задач. Рассмотрим структуру программы на примере пользователя с ролью "Пользователь UNISKAD", для которого установлены настройки по умолчанию.

После прохождения авторизации (см. пункт Авторизация) будет представлен интерфейс с возможными инструментами. По умолчанию пользователю доступны следующие пункты: «Файл», «Рабочие данные», «Словари», «Проекты», «Окно» «Помощь». Роль пользователя можно увидеть в правой верхней части экрана (как сказано выше в данном примере роль пользователя «Пользователь UNISKAD» (Рисунок 1).

Рассмотрим более подробно каждый пункт меню, сфокусировавшись на основных возможностях расположения окон.

По умолчанию каждому пункту меню присвоено определенное место. В левой части экрана расположено окно для просмотра дерева проекта под названием "Проекты".

В правой части экрана расположены окна для пункта "Изделия", "Словарь синонимов" и "Словарь единиц измерения" (Рисунок 2).
