Сохранение графика в формате XLSX

Нажатие на иконку , позволяет сохранить файл данного графика в формате XLSX на персональном компьютере пользователя (Рисунок 269).

Рисунок 269

При необходимости можно изменить имя файла, выбрать папку для сохранения, далее необходимо нажать на кнопку «Сохранить».
