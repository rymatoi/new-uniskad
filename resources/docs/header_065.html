Действия с неподтверждёнными синонимами

С каждым из неподтверждённых синонимов можно взаимодействовать, как и с любыми другими элементами программы. Для вызова контекстного меню следует нажать правой кнопкой мыши по данному синониму. После чего появится следующее меню (Рисунок 112).
