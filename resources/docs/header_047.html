Удаление рабочих данных

Для добавления объектов используется кнопка добавить при нажатии правой кнопки мыши (Рисунок 69).

Рисунок 69

В изделие мы можем добавить модель, в модель можно добавить сборку, в сборку можно добавлять испытания, папки и файлы. Важно отметить, что в каждый объект можно добавлять папку, которая в зависимости от места в иерархии будет хранить соответствующие элементы. То есть папка, созданная в изделии, будет хранить модели и т. д. (Рисунок 70).

Рисунок 70

Если будет выбран объект «Папка», то в самом дереве будет предоставлена возможность раскрытия/сокрытия элементов данной папки.

При нажатии правой клавишей мыши на объект откроется следующее меню (Рисунок 71)

Рисунок 71
