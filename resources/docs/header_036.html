Управление пользователями

Для управления пользователями следует выбрать соответствующий пункт в меню «Администрирование». После выбора пункта «Управление пользователями» в левой части экрана появится следующий интерфейс (Рисунок 49).

Рисунок 49

Примечание: если до этого не был закрыт пункт «Управление ролями», интерфейс «Пользователи» будет смещён вниз (Рисунок 50).

Рисунок 50

Управление пользователями аналогично управлению ролями, таким образом, для изменения настроек определённого пользователя следует нажать два раза на данного пользователя. После нажатия будут показаны параметры для изменения (Рисунок 51).
