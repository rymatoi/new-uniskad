Ввод неверного пароля пользователя

Количество попыток входа с неверным паролем управляется администратором и может быть вовсе отключено (по умолчанию установлено значение 5 неверных попыток). В случае ввода неверного пароля, оставшееся количество попыток будет показано пользователю в окне авторизации (Рисунок 13). После исчерпания лимита попыток входа пользователь будет автоматически заблокирован и не сможет войти в систему даже при вводе правильного имени пользователя и пароля. Разблокировка такого пользователя возможно только администратором.

После успешного ввода пароля меню авторизации будет закрыто и откроется интерфейс приложения. При этом количество доступных попыток входа (для входа в будущем) будет возвращено к значению по умолчанию для этого пользователя.

В случае ввода неверного имени пользователя выдается сообщение об этом, показанное на рисунке 14.
