Сохранение графика в формате PDF

Нажатие на иконку, содержащую изображение принтера в тулбаре , открывает диалоговое окно принтера. Пользователю необходимо выбрать «Microsoft Print to PDF» (Рисунок 266)

Рисунок 266

Нажав на кнопку «Печать», пользователь получить возможность выбора пути для сохранения этого файла в формате PDF (Рисунок 267)

Рисунок 267

Нужно ввести название файла и нажать кнопку «Сохранить». Данный файл будет сохранен по указанному пути.
